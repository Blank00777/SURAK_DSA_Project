3. FUNCTION REQUIREMENTS
================================================================================

FUNCTION 1: merge_sort_by_price(stocks) - 20 points
----------------------------------------------------
Algorithm: Merge Sort | Purpose: Sort stocks by price (ascending)

Requirements:
- Implement merge sort from scratch (NOT Python's sorted())
- Sort by PRICE
- Return NEW sorted list (don't modify original)
- Use divide-and-conquer recursive approach | Time: O(n log n)

Key Concepts:
- Base case: 0 or 1 element is already sorted
- Recursive case: divide, recursively sort halves, merge sorted halves
- You'll likely need a helper function to merge two sorted lists

Test: Menu option 2 displays stocks lowest to highest price


FUNCTION 2: binary_search_by_date(stocks, target_date) - 20 points
-------------------------------------------------------------------
Algorithm: Binary Search | Purpose: Find stock by date

Requirements:
- Implement binary search from scratch
- List is ALREADY sorted by date - DO NOT sort it
- Return index if found, -1 if not found (NOT None)
- Must be O(log n) - no linear search

Key Concepts:
- Initialize left=0, right=len(stocks)-1
- while left <= right: calculate mid, compare, adjust left/right
- Access date using stock.date attribute
- Watch for off-by-one errors

Test: Menu option 3 finds price for valid date (e.g., "2024-02-15")


FUNCTION 3: calculate_prefix_sum_prices(stocks) - 15 points
------------------------------------------------------------
Algorithm: Prefix Sum | Purpose: Calculate cumulative sums

Requirements:
- Create list where each element is sum of all prices from index 0 to i
- Formula: prefix[i] = prefix[i-1] + stocks[i].price
- Return list of floats (same length as input)

Example: Prices [100, 150, 120] → Prefix [100, 250, 370]

Key Concepts:
- prefix[0] = stocks[0].price
- For i from 1 to n-1: prefix[i] = prefix[i-1] + stocks[i].price
- EASIEST function - START HERE!


FUNCTION 4: calculate_moving_average(stocks, window_size) - 20 points
----------------------------------------------------------------------
Algorithm: Prefix Sum Application | Purpose: Calculate moving averages

Requirements:
- Use prefix sums (call calculate_prefix_sum_prices())
- Return list of tuples: [(date, average), ...]
- Only include averages with enough prior data
- Round to 2 decimal places

Formula:
- For index i >= window_size-1:
  avg[i] = (prefix[i] - prefix[i-window_size]) / window_size
- Edge case: when i == window_size-1, use prefix[i] / window_size

Test: Menu option 4 calculates moving average for any window size


FUNCTION 5: kadane_max_profit(stocks) - 20 points
--------------------------------------------------
Algorithm: Kadane's (Maximum Subarray) | Purpose: Find best buy/sell period

Requirements:
- Convert prices to daily changes: change[i] = price[i] - price[i-1]
- Apply Kadane's algorithm to find maximum sum subarray
- Track start/end indices of max subarray
- Return tuple: (buy_index, sell_index, max_profit)

CRITICAL: Buy index = ONE BEFORE where max subarray starts

Example: Prices [150,145,155,160,140] → Changes [-,-5,+10,+5,-20]
Max subarray: [+10,+5] → Buy index 1 ($145), Sell index 3 ($160), Profit $15

Test: Menu option 5 shows optimal buy/sell dates (should find buy: 2024-01-09
at $147.20, sell: 2024-03-19 at $186.90, profit: $39.70)
